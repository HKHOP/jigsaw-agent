Setting Up Your Development Environment 26.1.2 ​ A step-by-step guide on how to set up a development environment to create mods using Fabric. Install JDK 25 ​ To develop mods for Minecraft 26.1, you will need JDK 25. If you need help installing Java, you can refer to the Java installation guides . Set Up Your IDE ​ To start developing mods with Fabric, you will need to set up a development environment using IntelliJ IDEA (recommended), or alternatively Visual Studio Code.
