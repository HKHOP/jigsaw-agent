 /help 
 Running `/help` in the chat by itself will list every command you can run. However, since there are so many, they have been divided up into several pages, where you are shown only one page at a time. Supplying a page number will change which page of commands to show.Whenever you want to know the usage and all of the syntaxes of a command, you can use /help followed by the name of the command.
