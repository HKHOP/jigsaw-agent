All Sensors Inputs Outputs Power Transport Wire Observer sensor Detects block updates and emits a 1-tick redstone pulse. Redstone Comparator sensor Compares two signals OR reads container fullness. Redstone Repeater wire Delays and amplifies a redstone signal — also locks it. Sculk Sensor sensor Detects vibrations within 8 blocks and emits a redstone pulse. Calibrated Sculk Sensor sensor Sculk Sensor that only fires when the input frequency matches. Daylight Detector sensor Outputs redstone signal proportional to skylight level. Piston output Pushes up to 12 blocks one tile in the direction it's facing. Sticky Piston output Piston that pulls blocks back when retracting. Dispenser output Fires items as projectiles or places interactive items. Dropper output Drops items into the world or feeds them into containers. Redstone Lamp output Lights up when powered, going out 2 ticks after power removal. Note Block output Plays a tuned note when powered. 25 distinct pitches (2 octaves), instrument by under-block. Redstone Torch power source Always-on power-15 source. Inverts when its block is powered. Block of Redstone power source Always-on power-15 source. Movable by pistons. Lever input Toggle switch — power-15 ON, 0 OFF. Button input Momentary switch — pulses for 1 second (stone) or 1.5s (wood). Pressure Plate input Auto-trigger when stepped on. Variants by material (entity filter). Tripwire Hook input String-and-hook input that fires on entity crossing. Hopper transport Pulls items from above and pushes them into the container it points at. Crafter transport Auto-crafting block — first vanilla automated crafter. Target Block output Outputs redstone proportional to projectile-hit accuracy. Redstone comparisons Repeater vs Comparator — move a signal versus read one. Observer vs Comparator — trigger on a change versus gauge a level. Piston vs Sticky Piston — push-only versus push-and-pull. Dispenser vs Dropper — uses items versus just moving them. Hopper vs Dropper — automatic item flow versus pulsed ejection.
